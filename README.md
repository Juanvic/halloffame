## Goal
This is an fun project to study and improve my skills as developer so i'm planning to release small updates to it, the main goal is showcase a fully pokémon team in a way that the user can share their team with friends.

## Why this exists
In the recent Pokémon games released the function of a "Hall of Fame" don't exist anymore so the players don't have a way to visualize their team that beat the game so i build this to fill that void

## Development
This project has made using Vite + React, also with Javascript and using the famous api [Pokeapi](https://https://pokeapi.co/) huge thanks to team behind that project.
